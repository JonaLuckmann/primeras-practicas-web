# Primera página web hecha a mano

Trabajo final de un curso anterior de desarrollo web.

- **Fecha original:** 27 de marzo de 2023
- **Tecnologías:** HTML, CSS, PHP

Es un trabajo simple y de práctica, pero fue la primera página web hecha
a mano, así que se conserva como registro.

## Cómo verlo

1. Copiar la carpeta dentro del directorio que sirve Apache.
2. Abrir el archivo `index.php` desde el navegador, por ejemplo:
   `http://localhost/primeras-practicas-web/`
